# Personal Portfolio Website

This is my central portfolio website built to showcase my projects as an ML & Full-Stack Developer. 

### 🌐 Live Demo
**[View Live Portfolio](https://my-portfolio-two-omega-29.vercel.app/)**

### 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Styling:** Vanilla CSS (Custom Glassmorphism Design System)
- **Deployment:** Vercel

### ⚡ Features
- **Glassmorphism UI:** Modern, semi-transparent frosted glass panels.
- **Dynamic Projects Grid:** Scalable architecture separating Featured flagship apps from a compact "More Work" grid.
- **Fully Responsive:** Optimized for both mobile and desktop viewing.
